# Bootstrap Clone

Project kelompok untuk membuat clone halaman Bootstrap menggunakan HTML, CSS, dan Bootstrap.

## Pembagian Tugas
- Mahasiswa A: menyiapkan repository dan README.
- Mahasiswa B: membuat stylesheet di `assets/css`.
- Mahasiswa C: mengerjakan halaman `index.html`.
- Mahasiswa D: menyiapkan folder dan aset gambar di `assets/images`.
